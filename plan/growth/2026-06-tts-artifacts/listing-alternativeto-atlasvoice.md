## 4. Full description (the main body — paste into the description box)
AtlasVoice (also listed on WordPress.org as "Text To Speech TTS Accessibility") turns any WordPress
article into audio. Visitors get a one-click "Listen" player on posts, pages, and custom post types,
so they can listen instead of read — improving accessibility, dwell time, and engagement.

It works free out of the box using built-in browser and Google Translate voices (no API key needed).
The Pro version unlocks premium AI voice providers and converts content into downloadable, cacheable
MP3 files:

- **AtlasVoice AI** — built-in, free, 63 languages
- **Google Cloud TTS** — 300+ neural voices, 90+ languages
- **OpenAI / ChatGPT TTS** — 6 HD voices
- **ElevenLabs** — 100+ ultra-realistic voices, 29 languages

Key capabilities:
- MP3 generation + bulk export across your whole library
- Built-in listening analytics (engagement tracking + heatmaps)
- Audio schema markup for SEO rich results
- Six player styles plus a sticky/floating player, fully customizable
- CSS-selector targeting to include/exclude specific content
- Audio intros & outros for branding
- 51+ languages, multilingual sites supported
- WCAG accessibility compliance
- Works with all major page builders and caching plugins (no performance hit)
- Pronunciation aliases for correcting how names/acronyms are read aloud

Built by AtlasAiDev. Free version + Pro (from $59/yr or $199 lifetime, 14-day money-back guarantee).
Verified user feedback: 85 reviews on WordPress.org
(https://wordpress.org/support/plugin/text-to-audio/reviews/).
