# Gap Roles — not yet performed

> Companion to [roles-automation-plan.md](roles-automation-plan.md).
> The 14 roles already performed are covered there. This file lists the roles a web / AI
> application company still needs but that have **not been performed yet**.
>
> Company tagline: **"We build applications for a better experience with AI."**
> So AI is meant to be the *core*, not a bolted-on API.

---

## Roles not yet performed

| # | Gap role | What's missing today |
|---|----------|----------------------|
| 1 | **UX / UI Designer** | Deliberate product design, user flows, visual/brand design — beyond button customization. |
| 2 | **Sales / Conversion Closer** | Direct selling: pricing experiments, free→Pro conversion optimization, demo-to-close. |
| 3 | **AI / ML Engineer** ⭐ | AI-native features — prompt engineering, model selection, AI as core intelligence. Today = integrator, not builder. |
| 4 | **Finance / Bookkeeping** | Revenue tracking, cost of API/GCS bills, pricing math, runway. |
| 5 | **Legal** | ToS, licensing, contracts (compliance ≠ legal). |
| 6 | **Security Officer** | Dedicated security audits / pen-testing beyond wp.org escaping. |
| 7 | **Product Data Analyst** | Deep product-usage analysis to drive feature decisions (vs. business analytics only). |
| 8 | **Partnerships / BizDev** | Integrations, co-marketing, channel deals. |
| 9 | **HR / Team building** | Hiring / delegating to real people once solo capacity is exceeded. |
| 10 | **Customer Success** | Proactive onboarding / retention (vs. reactive support). |

---

## Priority order (which gaps to close first)

1. ⭐ **AI / ML Engineer** — the tagline demands it. This is what makes "better experience with AI"
   true instead of aspirational. Move from *integrating* AI to *building with* AI as the core.
2. **Sales / Conversion** — turns engineering + marketing into actual revenue.
3. **UX / UI Designer** — product feel and conversion both depend on it.
4. Finance, Legal, Security — needed as the business grows; lower urgency while solo.
5. HR, Partnerships, Customer Success — scale-stage roles; relevant once past solo.

---

## Note
This is a draft assessment — revise before acting. None of these are urgent to *fully staff*;
the point is awareness of where the company will need attention as it grows beyond a
one-person WordPress-plugin shop into a broader AI web-application company.
