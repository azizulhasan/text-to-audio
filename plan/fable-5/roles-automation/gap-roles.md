# Gap Roles — Fable 5 take

> **Status: DRAFT.** Original prompt: "Given the tagline *'We build applications for a better
> experience with AI'* and ambitions beyond WordPress plugins — which roles have I not performed yet?"

## Roles not yet performed

| Gap role | What's actually missing |
|---|---|
| **Sales / Conversion Owner** | Nobody runs pricing experiments, watches the free→Pro funnel, or closes. Marketing fills the top; nothing works the bottom. |
| **AI / ML Engineer (applied)** | AI is integrated (TTS APIs, providers) but not yet the product's core intelligence. |
| **UX / Product Designer** | No deliberate user-flow or visual design practice; customization ≠ design. |
| **Product Data Analyst** | Business metrics exist; per-feature usage data doesn't drive decisions yet. |
| **Finance** | No systematic revenue/cost/runway view (API bills, Freemius fees, pricing math). |
| **Security Officer** | wp.org escaping ≠ a security practice (audits, threat model, disclosure policy). |
| **Legal** | ToS, licensing, DPAs — compliance work exists, legal doesn't. |
| **Customer Success** | Support is reactive; nobody owns onboarding-to-value or churn. |
| **Partnerships / BizDev** | No integrations or channel deals. |
| **HR / Delegation to humans** | Everything above assumes AI can absorb it; some of it eventually needs a person. |

## Priority — and where I differ

1. **Sales / Conversion Owner — first.** You already have four shipped products and real traffic.
   The cheapest new revenue is conversion on what exists: pricing tests, upgrade prompts, funnel
   measurement. Weeks to impact, no new skills to learn.
2. **AI/ML Engineer (applied) — second, run in parallel.** It's the strategic direction (the tagline,
   the industry shift) but it pays off in quarters, not weeks. Do it as the *product* work it is.
3. **Product Data Analyst — third.** Cheap to stand up and it makes #1 and #2 measurably better.
4. Finance → Security → Legal as the business grows; CS/Partnerships/HR at scale.

> ⚖ Divergence from Opus 4.8: Opus put **AI/ML Engineer first** (tagline-driven); Fable puts
> **Sales/Conversion first** (cash-flow-driven), with AI/ML a very close second running in parallel.
> Rationale: a solo company's constraint is runway and attention; conversion work on existing products
> is the fastest compounding win and *funds* the AI-native bet. The tagline tells you where to go —
> revenue decides whether you get there.
