Frequently Asked Questions

What voice providers are supported?
AtlasVoice Pro supports 4 AI voice providers: AtlasVoice AI (included free with 63 languages), Google Cloud Text-to-Speech (300+ voices across 90+ languages), OpenAI / ChatGPT TTS (6 HD natural voices), and ElevenLabs (100+ ultra-realistic voices). The free version also includes browser-based Web Speech API voices. You can assign different providers to different post types.
Do I need API keys for voice providers?
AtlasVoice AI voices and browser-based voices work immediately with no API key required. For Google Cloud TTS, OpenAI, and ElevenLabs, you will need to create an account with each provider and enter your API key in the plugin settings. Each provider offers generous free tiers to get started.
What's included with the AtlasVoice AI voices?
AtlasVoice AI is our built-in voice engine that comes completely free with both the free and Pro versions of the plugin. It supports 63 languages with natural-sounding voices and does not require any external API key or account. It is the fastest way to add audio to your content.
Does it work with page builders?
Yes. AtlasVoice works seamlessly with all major WordPress page builders including Elementor, Divi, Beaver Builder, WPBakery, Oxygen, Bricks, and the native Gutenberg block editor. The audio player can be placed using our Gutenberg block, shortcode [tta_listen_btn], or automatic insertion. The CSS selector targeting feature in Pro lets you specify exactly which content gets converted to audio regardless of your page builder.
Is there a free version?
Yes. The free version of Text to Audio is available on WordPress.org with over 315,000 downloads. It includes browser-based voices, AtlasVoice AI voices, a basic audio player, Gutenberg block, shortcode support, and post type selection. Pro adds premium voice providers, MP3 generation, analytics, audio schema, additional player styles, and CSS selector targeting.
What's the refund policy?
All plans come with a 30-day money-back guarantee processed through Freemius. If you are not satisfied with the plugin for any reason, contact our support team within 30 days of purchase for a full refund — no questions asked.
How many languages are supported?
AtlasVoice Pro supports 51+ languages across its voice providers. AtlasVoice AI alone covers 63 languages. Google Cloud TTS adds 90+ languages with 300+ voices. The plugin integrates with popular multilingual WordPress plugins including WPML, GTranslate, and TranslatePress, so your audio automatically matches the visitor's language.
Does it affect site performance?
No. AtlasVoice is built with performance in mind. Audio is generated on demand or cached as MP3 files, so there is no impact on initial page load. The plugin is compatible with all major caching plugins including WP Rocket, LiteSpeed Cache, W3 Total Cache, Autoptimize, and SiteGround SG Optimizer. Our JavaScript files are automatically excluded from minification and deferral to prevent conflicts.
