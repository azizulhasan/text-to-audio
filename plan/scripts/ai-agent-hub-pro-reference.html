Frequently Asked Questions

Do I need the free plugin installed?
Yes. AI Agent Hub Pro is an add-on that extends the free AI Workflow Automation – AI Agent Hub plugin. The free plugin handles all the UI, abilities, and MCP server. Pro unlocks advanced features through WordPress filters — no code changes needed.
What AI providers are supported?
AI Agent Hub works with OpenAI (GPT-4o, GPT-4o-mini), Google AI (Gemini 2.5 Flash, Gemini 2.5 Pro), and Anthropic (Claude Haiku, Claude Sonnet). You bring your own API keys — the plugin does not include API credits.
What MCP clients can I connect?
Any client that supports the Model Context Protocol (MCP): Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and more. The plugin implements the full MCP 2025-06-18 specification with Streamable HTTP transport.
What happens if I cancel or deactivate Pro?
The free plugin continues to work normally with its default limits (3 workflows, basic access modes). Your settings are preserved and fully restored if you reactivate Pro later. No data is lost.
Is there a money-back guarantee?
Yes. All plans come with a 30-day money-back guarantee processed through Freemius. If you're not satisfied, contact support for a full refund — no questions asked.
What are Workflow Prompt Builders?
Prompt builders are pre-built, multi-step prompts designed for MCP clients. For example, the SEO Audit prompt orchestrates multiple abilities to analyze your content, check meta tags, evaluate readability, and generate a comprehensive report — all in one prompt.
Does it work with WooCommerce?
Yes. The Store Manager module includes 24 WooCommerce-specific abilities for managing products, orders, customers, coupons, and more. Pro adds the Store Dashboard prompt builder for instant store performance summaries.
