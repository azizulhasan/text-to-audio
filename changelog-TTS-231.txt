TTS-231 Changelog
=================
Branch: feature/TTS-231
Date: 2026-03-14

1. GDPR Privacy Compliance & Data Collection
   Added "Delete Data on Uninstall" toggle, enhanced uninstall cleanup,
   telemetry enrichment, and dual deactivation form submission.

2. Dashboard Code Splitting
   Split 701KB dashboard bundle into 240KB main + 9 lazy-loaded chunks
   (66% reduction) using React.lazy() and Suspense.

3. "Hear the Difference" — Setup Wizard Audio Demos
   Added new wizard step with audio previews for all 5 TTS providers
   (Browser, GTTS, Google Cloud, ChatGPT, ElevenLabs) using public
   CDN URLs and bundled MP3s. Added language-specific preview text
   for 68 languages and ElevenLabs demo support in Customize tab.

4. TTS-229: GTranslate Pro Version Language Fix
   Fixed GTranslate language detection to use <html lang> attribute
   instead of cookie/URL, with proper voice key mapping and title updates.

5. GTranslate Page Reload Loop Fix
   Fixed infinite reload loop when MP3 is deleted and frontend visited
   with GTranslate active, by adding shouldReload parameter to reload
   only on user-initiated language switches.

6. Audit Plan Updates
   Marked TTS-229, tasks 7.7-7.10, and code splitting as completed.
