# AtlasVoice logo: the Voice A (owner approved 2026-11-13, TTS-347)

A is for Atlas; its crossbar is three sound bars, the voice. Colours are the approved palette:
white on Voice Indigo `#5646e5`, coral `#ff7853` for the bars.

| File | Use |
|---|---|
| `atlasvoice-icon.svg` | App icon, 32 px and larger: WordPress.org icon (export 128 and 256 PNG), plugin header, websites |
| `atlasvoice-icon-small.svg` | 16 to 20 px: browser tab. The three bars merge into one so the A stays sharp |
| `atlasvoice-icon-dark.svg` | Dark surfaces (atlasvoice.cloud): tile `#8481f8`, mark `#0b0d1c` |
| `atlasvoice-mark.svg` | No tile, on white or light grounds |
| `atlasvoice-mark-white.svg` | One colour, on indigo or photos |
| `atlasvoice-mark-mono-small.svg` | WordPress admin menu icon (`currentColor`, so WordPress colours it) |

Rules: tile corner radius is 22% of its side. Keep clear space of a quarter of the tile around
it. Wordmark: "Atlas" in the text colour, "Voice" in indigo, weight 600. Do not recolour,
rotate, outline or put the coral bars on a coral or red ground. The bars may animate once
("speak") where motion is allowed; never under reduced motion.
